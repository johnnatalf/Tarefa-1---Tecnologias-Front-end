Projeto de Pesquisa / TCC

Identificação Precoce da Evasão Escolar no Ensino Básico

A evasão escolar reflete profundas desigualdades sociais e econômicas. Este projeto propõe o desenvolvimento de uma plataforma analítica para identificar padrões de risco e apoiar gestores públicos na permanência dos estudantes em sala de aula.

Ver Detalhes Contato

Visão Geral do Desenvolvimento

Como estruturamos a pesquisa e a tecnologia para combater o abandono escolar.

Funcionalidades

Cruzamento de dados de frequência escolar, notas e indicadores socioeconômicos para gerar alertas automatizados às secretarias de educação sobre alunos em situação de vulnerabilidade e risco de abandono.

Tecnologias

O ecossistema utilizará Python para a análise exploratória e engenharia de dados, banco de dados estruturado para armazenamento seguro das informações institucionais, e uma interface web limpa com componentes do Bootstrap.

Impacto & Diferencial

Permite uma atuação preventiva em vez de reativa. Ao antecipar o abandono escolar, gestores e pedagogos conseguem aplicar intervenções direcionadas, otimizando os recursos públicos e salvando trajetórias acadêmicas.
